Privacy Policy

USA Explained Publisher · Last updated: November 8, 2026 · Home

Who uses this tool?

This tool is used only by the owner of the USA Explained YouTube channel, for that channel only. It is not available to other users.

What data does it access?

  • the OAuth access token granted by the channel owner's Google account,
  • the channel's own videos, descriptions, captions, thumbnails, playlists and comments,
  • the channel's own view and audience retention (analytics) data.

No data about other people is collected. No personal data of viewers is stored; public comments are read only for the channel's own videos.

How is it used and where is it stored?

The data is used only for the tasks above and is stored only on the channel owner's own computer. It is never shared with third parties, sold or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This tool uses YouTube API Services. See the Google Privacy Policy.

Removing access

The channel owner can revoke this tool's access at any time at myaccount.google.com/permissions. Once access is revoked, the tool can no longer reach any data.
